# babidzgon-rep — команда AI-агентов для Claude Code

34 специализированных субагента в `.claude/agents/` и правила оркестрации в `CLAUDE.md`.

Как пользоваться: откройте этот репозиторий в Claude Code и дайте сложную задачу. Основная сессия
(«главный мозг») разобьёт её на части и раздаст агентам. Вызвать конкретного агента можно и напрямую:
«пусть `smm-manager` сделает контент-план на неделю».

Полный ростер и протокол — в [CLAUDE.md](CLAUDE.md).
