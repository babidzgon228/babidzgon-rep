# Дизайн-система бота

Визуальный концепт с макетами: https://claude.ai/artifact/GjhuxXxnPYVdjmpXSMFc2w
Этот файл — обязательные правила для всех, кто пишет экраны. Если правило мешает, сначала обсуди его, не нарушай молча.

## 1. Принципы
1. **Модули по выбору.** Каждая группа функций — модуль, который можно выключить. Выключенный модуль не виден
   в меню, не шлёт уведомлений и не попадает в дайджест.
2. **Пишешь как человеку.** Любой свободный текст и голосовое сообщение уходят ИИ-парсеру. Кнопки нужны для быстрых
   действий, а не как единственный способ ввода.
3. **Одно сообщение — один экран.** Навигация и переключатели редактируют сообщение на месте (`edit_text`).
   Новое сообщение появляется только в ответ на ввод пользователя и в уведомлениях.
4. **Главное действие первым.** Сначала самое частое действие, навигация в конце.
5. **Юмор — приправа.** Не больше одной шутки на экран, курсивом, в конце. Если пользователь пишет о плохом
   самочувствии или усталости, бот не шутит.

## 2. Анатомия сообщения
```
<эмодзи раздела> <b>Заголовок</b> · контекст (дата / город / счётчик)
<строка статуса: прогресс ▰▰▰▱ · 🔥 стрик · ⭐ XP>      ← не больше 1 строки, можно пропустить

<блок контента: до 7 строк, время слева HH:MM>
                                                       ← пустая строка между блоками
<блок контента>

<i>подсказка или шутка</i>                             ← не больше одной, по желанию
```
Помощники в `bot/ui/texts.py`: `title()`, `bar()`, `esc()`, `fmt_*`, `plural()/count()`. Новые компоненты добавляй
туда же, а не копируй по хендлерам.

## 3. Кнопки (inline)
- Не больше 3 в ряду и 5 рядов на экране. Длинные списки листаются страницами `◀️ 1/3 ▶️`.
- Переключатели показывают состояние: `✅ Включено` / `☐ Выключено` (helper `mark()`).
- `◀️ Назад` всегда в последнем ряду слева, `✖️ Отмена` в мастерах тоже в последнем ряду.
- Удаление (`🗑`) всегда с подтверждением, а удалённое 30 дней лежит в корзине.
- В уведомлениях всегда есть быстрые действия: `✅ Сделано`, `⏰ 5 / 10 / 30 мин`, при необходимости `⏭ Пропустить`.
- `callback_data` не длиннее 64 байт, только через `CallbackData`-фабрики из `bot/ui/callbacks.py`.
- Каждый `callback` закрывается `ack()` (в том числе с коротким текстом-тостом: «Готово ✅»).

## 4. Главное меню (reply-клавиатура)
Три ряда по три кнопки. Состав собирается из включённых модулей:
```
🏠 Сегодня   ✅ Задачи    ➕
🎓 Учёба     🔥 Привычки  💰 Деньги
⏱ Фокус     📊 Прогресс  ⚙️ Ещё
```
Если модуль выключен, его место занимает следующий. «Сегодня», «Задачи», «➕» и «Ещё» есть всегда.

## 5. Словарь значков
| | | | |
|---|---|---|---|
| ▶ сейчас | ⏭ дальше | 📚 пара | 📌 событие |
| ⏰ дедлайн | 🔔 напоминание | 🔥 стрик / срочно | ❄️ заморозка стрика |
| ⭐ XP | 🪙 монетки | 📥 входящие | ☑ подзадачи 1/4 |
| 🔴 P1 важно | 🟠 P2 обычно | 🟢 P3 мелочь | 🏷 @контекст |
| ✅ готово | ☐ не сделано | ◐ частично | 💧 вода |

Прогресс-бар: 8 или 10 сегментов `▰▱` (`texts.bar`). Проценты пишем рядом цифрой.

## 6. Пустые экраны и ошибки
- Пустой экран состоит из шутки и одного действия: «Подозрительно чисто 🤨 Добавь первую задачу» + `[➕ Добавить]`.
- Ошибка объясняет, что не так и что сделать дальше: «Не понял дату 🤔 Напиши как 12.11 или 12.11 18:00».
  Извинения, технические детали и traceback пользователю не показываются.

## 7. Языки
- Все строки берутся только через `bot.i18n.t(key, lang)` / `tp(key, n, lang)`; язык определяется через `L(user)`.
- Ключи именуются `<модуль>.<экран>.<что>`: `tasks.empty`, `habits.streak`, `menu.today`.
- Новый ключ добавляется сразу в `ru.py`, `en.py`, `zh.py`: тест `tests/test_i18n_core.py` проверяет, что каталоги совпадают.
- Китайский текст пишется естественно, без дословного перевода. Шутки адаптируются под язык, а не переводятся.
- Кнопки меню распознаются на любом языке (`i18n.all_langs(key)`).

## 8. Модули (архитектура)
Каждый модуль — пакет `bot/modules/<key>/`:
```
__init__.py   MODULE = Module(key=..., emoji=..., hub=..., default_on=..., router=..., schema=..., hooks...)
handlers.py   router() -> Router
texts.py      форматирование экранов (через i18n)
keyboards.py  клавиатуры
service.py    логика и SQL (свои таблицы через schema, без правки bot/db.py)
```
Модуль регистрируется в `bot/modules/registry.py`. Хуки: `digest_lines` (строки в утреннем и вечернем дайджесте),
`notifier_tick` (свои напоминания с дедупликацией через `db.mark_sent`), `today_lines` (строки на экране «Сегодня»).
Включённость модуля хранится в `user.settings.modules` (`registry.enabled(user, key)`).

## 9. Чек-лист экрана перед сдачей
- [ ] Заголовок по анатомии, статус-строка не длиннее одной строки
- [ ] Главное действие первое, «Назад» последнее
- [ ] Пустое состояние с юмором и действием
- [ ] Строки через i18n на трёх языках
- [ ] Пользовательский текст экранирован (`esc`)
- [ ] Время показано в часовом поясе пользователя
- [ ] Тест: экран рендерится, `callback_data` ≤ 64 байт
