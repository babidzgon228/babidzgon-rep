# 🗓 Личный бот-планировщик в Telegram

Бот следит за тем, чем ты занят, расставляет задачи по эффективности, каждый вечер сам составляет
план на завтра, напоминает о парах и событиях. Внутри ИИ-ассистент на Claude.

- 🎨 Дизайн-концепт с макетами экранов и дорожной картой: https://claude.ai/artifact/GjhuxXxnPYVdjmpXSMFc2w
- 📐 Правила дизайна для разработки: [`docs/DESIGN.md`](docs/DESIGN.md)
- 🆓 Как запустить бесплатно 24/7 (в том числе из Китая): [`docs/DEPLOY.md`](docs/DEPLOY.md)

## Что умеет

| | |
|---|---|
| ⏱ **Трекер** | Таймер по категориям (учёба, работа, спорт, отдых…), оценка продуктивности 1–5, запись прошедшего. Бот сам периодически спрашивает «Что делаешь сейчас?» |
| ✅ **Задачи по эффективности** | Важность, дедлайн, сколько времени займёт, насколько сложная. Бот считает приоритет 0–100, раскладывает задачи по матрице Эйзенхауэра и объясняет, почему у задачи такой приоритет |
| 🗓 **План на завтра** | Каждый вечер сам: пары и события стоят фиксированно, задачи ложатся в свободные окна (сложное ставится на пик продуктивности), перерывы, еда. Кнопки: принять / перестроить / улучшить с ИИ / получить картинкой |
| 🔔 **Уведомления** | Утренняя сводка, напоминания о парах и событиях, о блоках принятого плана и о дедлайнах (за 24 ч и за 2 ч), вечерний отчёт за день |
| 🤖 **ИИ (Claude)** | Пиши боту обычным текстом: «завтра в 15 встреча с куратором», «надо сделать эссе по экономике до пятницы, часа 3», «что у меня в среду?», «начал учить иероглифы». Ассистент сам создаёт задачи и события, ведёт трекер, улучшает план, разбирает итоги дня, распознаёт расписание по фото |
| 🎓 **Расписание** | Уже внесено (осенний семестр). Поддерживаются чётные и нечётные недели и границы семестра, в каникулы пары не показываются. Редактируется кнопками или загрузкой фото |
| 🌍 **Шэньчжэнь ↔ Москва** | Часовой пояс переключается сам: сентябрь–январь и март–15 июля — Шэньчжэнь (UTC+8), в остальное время — Москва (UTC+3) |
| 📊 **Статистика** | День, неделя и месяц: время по категориям, доля продуктивного времени, выполненные задачи, «эффективность дня» 0–100 |

## Запуск за 5 минут

### 1. Получи токены
1. **Токен бота:** напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя → скопируй токен.
2. **Твой Telegram ID:** напиши [@userinfobot](https://t.me/userinfobot). Он нужен, чтобы ботом пользовался только ты.
3. **Ключ Claude API** (по желанию, без него бот работает, но без ИИ): [console.anthropic.com](https://console.anthropic.com) → API Keys.
   Claude API доступен не во всех странах, список поддерживаемых стран есть на сайте Anthropic.

### 2. Настрой
```bash
git clone https://github.com/babidzgon228/babidzgon-rep.git
cd babidzgon-rep
cp .env.example .env      # Windows: copy .env.example .env
```
Открой `.env` и впиши `BOT_TOKEN`, `ALLOWED_USER_IDS` и, если есть, `ANTHROPIC_API_KEY`.

### 3. Запусти

**Вариант А: на своём компьютере** (бот работает, пока включён компьютер):
```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

**Вариант Б: на сервере 24/7 через Docker** (рекомендуется, иначе уведомления не придут, когда компьютер выключен):
```bash
docker compose up -d --build
docker compose logs -f              # посмотреть логи
```

> ⚠️ **Про Китай.** Telegram заблокирован в материковом Китае. Либо запускай бота на сервере за его
> пределами (бесплатно, например Oracle Cloud), либо на своём компьютере с прокси: впиши в `.env`
> `TELEGRAM_PROXY=http://127.0.0.1:7890` (порт твоего VPN-клиента). Подробности в [`docs/DEPLOY.md`](docs/DEPLOY.md).

### 4. Открой бота в Telegram → `/start`
При первом запуске бот сам загрузит твоё расписание и режим дня из `data/timetable.yaml`.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и быстрая настройка |
| `/today`, `/tomorrow` | План на сегодня и на завтра |
| `/plan` | Собрать план на завтра прямо сейчас |
| `/tasks`, `/add` | Список задач по приоритету, добавить задачу |
| `/event` | Добавить событие с напоминанием |
| `/track`, `/stop` | Запустить и остановить трекер |
| `/stats` | Статистика |
| `/week` | Учебное расписание на неделю |
| `/settings` | Настройки: пояс, режим дня, уведомления, ИИ |
| `/ai` | Режим ИИ-ассистента |
| `/help` | Помощь |

Внизу всегда есть меню кнопками, так что команды помнить не обязательно.

## Как поменять расписание
- **В боте:** 🎓 Расписание → добавить или удалить пару, либо 📷 загрузить фото или текст (ИИ распознает).
- **В файле:** правишь `data/timetable.yaml`, удаляешь `data/bot.db` и перезапускаешь бота (все данные будут сброшены).

## Голосовые сообщения
Отправь боту голосовое, он распознает речь и обработает её как обычный текст. Распознавание идёт
на сервере бесплатно, но требует около 1 ГБ RAM: `pip install -r requirements-voice.txt`.
